## 如何读核验标签

- **已核对原帖/发布者页面**：读取了来源的模型归属；不等于独立复现。
- **玩法改写简报**：本库根据公开玩法撰写，原始效果不证明改写提示词能复现。
- **原文入口**：完整提示词在来源查看，或未公开；详情页会区分。
- **原创未实测**：可编辑起点，尚未生成验证。

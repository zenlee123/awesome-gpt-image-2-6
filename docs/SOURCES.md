# Sources and verification / 来源与核验

Updated **2026-11-07** (Asia/Shanghai). This repository separates **source
workflows**, **copy-ready text**, and **independent reproduction**.

## What the numbers mean

- A source workflow is one creative task, not one image. Model comparison images
  and repeated outputs stay within the same case.
- A copy-ready entry has English and Chinese text in `data/prompts.json`.
  It may be an editorial adaptation, a recreation brief, or an original template.
- A source-link entry provides the original URL and available media. It is not
  counted as a copy-ready prompt.
- No case has been independently generated by this repository.

   The fetch/model-mention log is [source-audit.json](../data/source-audit.json).

The launch examples whose primary page could not be fetched, and the two
Reddit leads without a confirmed model label in fetched text, remain marked
**secondary-only**. A publisher's own source is marked **publisher-page-checked**;
it is not treated as OpenAI documentation or as an independent benchmark.

## Popularity evidence

Only explicit view counts read from the original X posts are recorded. Each
record stores the permalink, date, displayed value, numerical approximation
and timestamp. Values such as `22K` are not exact counts. The table compares
only tracked posts and is not a global ranking. A source website having an
example does not establish that it is popular.

## Media and prompt relationship

Media stay linked to their source hosts. Input/output roles are retained from
the discovery catalogue where available; unclassified images say “source”.
Comparisons can contain older-model outputs: captions, rather than the 2.6
case title alone, identify those images. Do not count those as additional 2.6
cases. External media URLs can change or become unavailable.

New **recreation briefs** are written by this repository. They are not quoted
original prompts, and their source previews are not results of those briefs.
Where a full prompt was unavailable, the source-only record stays explicit;
we do not infer the author's missing prompt from an image.

# Sources and verification / 来源与核验

Snapshot date: **2026-11-07** (Asia/Shanghai).

## Primary documentation checked

- [OpenAI changelog](https://developers.openai.com/api/docs/changelog):
  November 4 release of GPT Image 2.6 Sunburst and Flare.
- [Image generation guide](https://developers.openai.com/api/docs/guides/image-generation):
  complexity control, markup-guided editing, SVG and animated GIF output.
- [Image prompting guide](https://developers.openai.com/api/docs/guides/image-prompting):
  official object-removal and winter-scene editing examples.

Model names: `gpt-image-2.6-sunburst` and `gpt-image-2.6-flare`.
Availability depends on the product/account. A prompt does not set an API output
format. Check the current official guide for output options and request fields.

## Source discovery

[EvoLink's collection](https://github.com/Evolink-AI/awesome-gpt-image-2-6-prompts-and-api)
was inspected through its default branch, `codex/gpt-image-2-5-prompts`.
The 2.6 case file at blob `9f393c90e0d4e0235ec04a95b9433f59cc585741`
contains nine 2.6-labeled cases (251–259).
The remaining 250 entries are labeled 2.5 and are not counted here.

Seven creator cases were found through that collection. Their original X
permalinks are retained, but their contents and engagement counts were not
independently retrieved during this snapshot. Those entries are explicitly
`secondary-only`, not verified viral posts. The two official examples were
checked against OpenAI documentation. No entry was independently regenerated.

Media links point to the reference collection's hosted previews and may change
or disappear. They are examples from the source, not results generated here.
No third-party media binaries are copied into this repository.

## Selection and popularity

The repository tracks useful public workflows with an aim to collect global
trends. Inclusion alone does not establish popularity. There is currently no
verified global ranking; every entry has `popularity: null`.

To add a trend claim, record its platform metric, count, permalink and observation
date. Compare like metrics over the same interval. Views are not likes, and one
post is not an independent reproduction. Do not infer geographic popularity
from a creator's display language.

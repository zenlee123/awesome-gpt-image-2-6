# Earlier model collections / 旧版模型资料

The [EvoLink reference collection](https://github.com/Evolink-AI/awesome-gpt-image-2-6-prompts-and-api)
contains 250 earlier **GPT Image 2.5** cases in seven categories. They are useful
inspiration, but this repository does not relabel them as GPT Image 2.6 results.

旧版案例保留在原仓库：人像、角色设定、插画、广告、旅行手账、图片编辑及连续分镜。
如果在 2.6 上重新测试，请作为新复现提交，并记录模型、输入、参数与输出；不要直接
把旧图片改标成 2.6。

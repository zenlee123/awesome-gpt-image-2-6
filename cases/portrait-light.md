
## Workflow

1. Check inputs, model variant and output format at the source.
2. Customize the brief, or read the original prompt for source-link entries.
3. Iterate one change at a time; inspect text, identity, geometry and preserved regions.
4. Select GIF / SVG in your tool when needed; prompt wording does not set API parameters.

## 使用方法

1. 先核对原文中的输入素材、模型变体与输出格式。
2. 有提示词时按需替换主体和文字；仅链接案例先阅读来源。
3. 初次只做一处修改，再检查文字、身份、几何与未修改区域。
4. 需要 GIF / SVG 时在工具中选择相应格式；文字指令不代替 API 参数。
